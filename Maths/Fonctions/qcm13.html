Corrections Détaillées

1. À quel ensemble appartient le nombre √(2) ?

Réponse : d) ℝ mais pas ℚ

Explication : √2 est irrationnel car il ne peut pas être exprimé comme un rapport de deux entiers. Il appartient à ℝ mais pas à ℚ.

2. Quel est l'encadrement de π à 10-2 près ?

Réponse : b) 3,14 < π < 3,15

Explication : π ≈ 3.14159, donc à 10^{-2} près (au centième), l'encadrement est 3.14 < π < 3.15.

3. L'arrondi de 7,856 à l'unité près est :

Réponse : b) 8

Explication : Le chiffre des dixièmes est 8 ≥ 5, donc on arrondit à l'unité supérieure : 8.

4. Traduisez l'inégalité -2 ≤ x < 5 en intervalle.

Réponse : b) [-2, 5[

Explication : Inclus -2 (crochet [), exclu 5 (crochet [ inversé).

5. Soient A = [-3, 1] et B = [0, 4]. Quelle est l'union A ∪ B ?

Réponse : a) [-3, 4]

Explication : L'union couvre de -3 à 4 sans trou car les intervalles se chevauchent.

6. Résolvez l'équation |x - 3| = 2.

Réponse : a) x = 1 ou x = 5

Explication : |x - 3| = 2 ⇒ x - 3 = 2 ou x - 3 = -2 ⇒ x = 5 ou x = 1.

7. Résolvez l'inéquation |x + 1| ≤ 4.

Réponse : a) x ∈ [-5, 3]

Explication : -4 ≤ x + 1 ≤ 4 ⇒ -5 ≤ x ≤ 3.

8. Interprétez |x - 2| < 1 comme un intervalle.

Réponse : b) x ∈ ]1, 3[

Explication : -1 < x - 2 < 1 ⇒ 1 < x < 3.

9. Soit l'inéquation |2x - 4| > 6.

Réponse : a) x < -1 ou x > 5

Explication : |2x - 4| > 6 ⇒ 2x - 4 > 6 ou 2x - 4 < -6 ⇒ 2x > 10 ou 2x < -2 ⇒ x > 5 ou x < -1.

10. Traduisez l'intervalle ]-∞, -2[ ∪ ]3, +∞[ en inégalité avec valeur absolue.

Réponse : d) |x - 0.5| ≥ 2.5

Explication : Le centre est ( -2 + 3 ) / 2 = 0.5, distance 2.5, et ≥ pour l'extérieur.

11. Quelle est le domaine de définition de f(x) = √(x - 1) ? (2 points)

Réponse : b) x ∈ [1, +∞[

Explication : Pour que la racine soit définie, x - 1 ≥ 0 ⇒ x ≥ 1.

12. Pour f(x) = 2x + 3, calculez l'image de x = -1.

Réponse : a) 1

Explication : f(-1) = 2*(-1) + 3 = -2 + 3 = 1.

13. Pour la même fonction, trouvez l'antécédent de 7.

Réponse : a) x = 2

Explication : 2x + 3 = 7 ⇒ 2x = 4 ⇒ x = 2.

14. Sur la courbe de f(x) = x², le point (2, 4) appartient-il à la courbe ?

Réponse : a) Oui

Explication : f(2) = 4, donc le point (2, 4) est sur la courbe.

15. À partir d'une calculatrice, pour f(x) = 3x - 1, dressez un extrait de tableau de valeurs pour x = 0, 1, 2. (2 points)

Réponse : a) f(0) = -1, f(1) = 2, f(2) = 5

Explication : f(0) = -1, f(1) = 3*1 - 1 = 2, f(2) = 3*2 - 1 = 5.

16. Pour résoudre graphiquement x² - 4 = 0, on cherche les intersections de y = x² avec :

Réponse : b) y = 4

Explication : x² = 4, donc intersection avec la droite y = 4.

17. Sur le graphique de f(x) = 1/x, l'image de x = 2 est :

Réponse : a) 1/2

Explication : f(2) = 1/2.

18. Le domaine de définition de g(x) = 1/(x - 2) est :

Réponse : b) ℝ \ {2}

Explication : Indéfinie en x = 2 (division par zéro).

19. Intersection de A = ]-1, 3[ et B = [2, 5[. (2 points)

Réponse : a) [2, 3[

Explication : Chevauchement de 2 (inclus de B) à 3 (exclu de A).

20. Pour h(x) = |x|, l'antécédent de 3 est :

Réponse : c) x = 3 ou x = -3

Explication : |x| = 3 ⇒ x = 3 ou x = -3.
